# OshiCal Server 0.3.8

本次仅发布服务端（含宿主机更新代理脚本修复），标签为 `server-v0.3.8`。桌面端保持 `0.3.5`，不再重复发布。

## 修复更新代理心跳为空

`oshical-updater-agent.sh` 的 `safe_replace_file` 和 `safe_append_file` 原先同时使用 stdin 读取内嵌 Python 脚本和管道数据，导致写出的心跳文件、状态文件和更新日志为空。服务端因此会把仍在执行的代理误判为离线。

本次修复为：

- 将管道数据复制到文件描述符 `3`，内嵌 Python 脚本继续从 stdin 读取。
- 心跳、状态和更新日志改从文件描述符 `3` 读取数据。
- 增加静态回归测试，防止两个写文件助手再次把 stdin 同时当作脚本和数据源。
- 已在测试宿主机验证：更新代理空闲时心跳文件持续刷新，timer 服务结果为 `success`。

## 兼容性

- 桌面端 `0.3.5` 已兼容运行中但心跳暂时过期的旧服务端响应。
- 宿主机更新代理需升级到本版本仓库中的 `scripts/oshical-updater-agent.sh`，心跳和状态才能可靠写入。
- `scripts/update-server.sh` 未修改，测试宿主机现有自定义部署脚本保持不动。

## 验证

- 本机只做源码、差异和静态检查，不执行构建或测试。
- 前端测试、Rust 格式、Clippy、测试、服务器镜像和便携包全部由 GitHub Actions 构建验证。
