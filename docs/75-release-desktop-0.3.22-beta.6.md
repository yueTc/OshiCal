# 桌面客户端 0.3.22-beta.6（测试版）

本版基于已发布的桌面测试版 `0.3.22-beta.5`，合并直播数据弹层与设置弹层的界面收口调整。桌面端版本递增为 `0.3.22-beta.6`；服务端版本、数据库结构和更新渠道不变。

## 体验变化

- 直播数据弹窗和“同接变化”弹窗移除与右上角 X 重复的底部“关闭”按钮，统一使用右上角 X 或点击遮罩关闭。
- B 站扫码登录弹窗移除底部“关闭”按钮，保留“重新生成”操作。
- 选择模型弹窗移除底部“关闭”按钮。
- “同接变化”弹窗改为固定弹层布局，标题和右上角关闭按钮保持可见，内容区独立滚动并隐藏可见滚动条。
- 移除“同接变化”中的统计口径、原始观测时间和空白区间说明，保留曲线、采样时间滑块及核心统计信息。
- 编辑日程、保存设置、删除确认、数据迁移等包含独立决策或主操作的弹窗不受影响。

## 数据与兼容性

- 不改变数据库结构、API、环境变量、更新渠道或默认设置，无需迁移数据。
- 本次只影响桌面客户端界面，不修改服务端版本，不移动 `desktop-beta`、桌面正式版 latest 或其他更新清单。
- 升级前建议备份客户端完整数据目录；本地数据模式至少备份 `%APPDATA%\com.oshical.desktop\oshical.db` 及相关 `-wal`、`-shm` 文件。

## 下载与安装

- 版本：`0.3.22-beta.6`。
- 普通用户使用 Windows x64 NSIS 安装包：`OshiCal_0.3.22-beta.6_x64-setup.exe`。
- 本次为本地构建，不发布 GitHub Release，不更新在线检查所用的测试版或正式版清单；已安装用户不能通过在线更新取得本包。
- 本地构建未生成 Tauri updater 签名，且未配置 Windows Authenticode 代码签名，Windows 可能提示“未知发布者”。

## 升级与回滚

- 可直接覆盖安装本版；如需回滚，请重新安装上一份桌面安装包。
- 覆盖安装前先确认本地数据已备份，避免用旧数据库备份覆盖安装后产生的新记录。
- 本地包未执行真实安装、覆盖安装和自动更新验证；安装后建议检查直播数据、同接变化、扫码登录和模型选择弹窗的关闭行为。
