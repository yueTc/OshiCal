# 推历 OshiCal 桌面端 0.3.23-beta.1 测试版

本版是 `0.3.23` 测试周期的首个版本，相对上一桌面发布版本 `0.3.22`，调整主播库操作入口，增加最近直播记录及单场数据查看。不包含服务端或共享核心数据层改动。

## 新增与体验变化

- 主播库每位主播新增三点“更多操作”菜单。“设定周表”“设置别名”收进菜单，原有编辑功能不变；刷新日程、进入直播间和删除主播仍保留原入口。
- 在更多菜单选择“查看最近直播”，以日程卡片样式列出该主播最近最多 50 场已采集直播，按实际开播时间倒序显示日期、时间、直播标题及直播中/已结束状态。列表不包含未来周表、预告或未采集的历史直播。
- 点击卡片直接打开该场直播数据，包括时长、估算营收、付费与互动人数、弹幕及数据完整度提示；无需先在日历中查找对应日期，即使历史场次没有关联日程也可查看。
- 点击统计中的“最高同时在线”可查看该场公开高能用户数采样曲线，与日程页共用同一统计详情和曲线界面。可返回最近直播列表继续查看其他场次；返回时恢复所选卡片的键盘焦点。
- 最近直播支持手动刷新、加载提示、读取失败重试与无记录说明；关闭窗口后忽略尚未完成的旧列表响应。更多菜单支持方向键、Home/End、Escape，并在窄窗口内调整位置。

## 数据、配置与兼容性

- 无新增数据库迁移、必填环境变量或设置项，不改变现有周表、别名、订阅及更新渠道。此功能仅使用既有直播场次列表和采样读取接口；本地模式读取本机，服务器模式读取当前连接的服务器。
- 服务器模式建议使用服务端 `0.3.30` 或支持既有直播场次与在线采样接口的兼容版本。服务器不可用时显示读取失败，可恢复连接后重试；不会把其他数据源的场次混入列表。
- 直播数据需要事先在“设置”开启统计，并在主播库打开该主播的“订阅直播数据”，直播期间保持采集端运行。未采集的历史场次不会补造；暂时关闭统计后仍可查看已保留的场次记录。
- 营收、付费人数及互动人数沿用现有估算口径，缺失/失败指标继续明确标识。人数曲线表示公开高能用户数，不等于全体观众真实同接，历史缺失采样不会补造。

## 下载、安装与渠道

- 版本与标签：`0.3.23-beta.1` / `desktop-v0.3.23-beta.1`，仅发布到测试版渠道；产品 Release 应标记为 prerelease，固定测试清单为 `desktop-beta`，不移动正式版清单。
- 普通用户下载 Windows x64 **NSIS 安装包** `OshiCal_0.3.23-beta.1_x64-setup.exe`。已安装用户可在“设置 → 软件更新”切换到测试版渠道并检查更新。
- 自动更新包使用 **Tauri 签名校验**。当前发布工作流未配置 Windows Authenticode 代码签名，Windows 仍可能提示“未知发布者”；仅使用本项目 Release 或客户端内的更新来源。
- 测试版渠道继续同时读取测试版和正式版清单，按 SemVer 选择较高版本，不后台降级。主动切回较低正式版时，需按客户端提示确认显式降级。

## 升级前操作、已知限制与回退

1. 升级前备份完整客户端数据目录及服务器连接配置；本地模式退出客户端后备份 `%APPDATA%\com.oshical.desktop`，包括数据库及必要的 WAL。服务器数据请另行做完整备份，不要将 JSON 快照视为完整统计数据库备份。
2. 最近直播只显示最近最多 50 场已采集记录，暂不提供更早记录分页或按日期筛选；不能代替完整历史日程浏览。
3. 本地开发阶段仅完成源码静态诊断，未在本机执行构建、测试或安装验收。新增排序/筛选回归及真实 App 浏览器交互用例已接入现有 CI；发布前应由 GitHub Actions 完成验证、构建与签名，并核对安装升级结果。
4. 如需回退，先保存当前完整数据，再手动安装上一正式版 `0.3.22`，必要时恢复升级前备份。旧版本没有本版新增的主播库入口，恢复旧备份会丢失备份后的记录；自动检测不会替用户执行降级。

正式版需在本测试版验证后另行确认，本次不发布正式版。
