# OshiCal Server 0.3.1

本次仅发布服务端，标签为 `server-v0.3.1`。桌面端与核心库的包版本保持 0.3.0。

## 修复

- 已登录时，直播采集使用同一份 Cookie 快照获取弹幕 token、账户 UID 和 buvid，避免扫码登录后仍以匿名身份采集。
- 登录或退出后，已有采集连接会检测凭据变化并重新认证；登录态失效时报告采集失败，不静默回退匿名 token。
- 礼物、SC 和舰长事件的顶层 UID 为零或缺失时，补读发送者信息中的 UID，按同一 UID 去重，不将收礼人计入付费人数。
- 付费事件缺少可识别的发送者时保留营收，并将统计质量标为不完整。

## 限制

历史漏采的用户标识无法从累计营收补回。跨进程重启的用户集合仍未持久化，整场唯一人数仍可能存在去重误差。

## 验证与发布

新增登录身份校验、登录切换时的凭据快照隔离、跨付费事件用户去重，以及收礼人不计入付费人数的回归用例。
本机只做源码格式和差异检查；构建、测试和镜像发布由 GitHub Actions 执行。
