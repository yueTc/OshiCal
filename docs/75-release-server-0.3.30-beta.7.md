# 服务端 0.3.30-beta.7（测试版）

本版相对 0.3.30-beta.6，补充直播卡片绑定的旧客户端兼容标记，并确保断流重连使用本场首次开播时间。配套桌面客户端为 0.3.22-beta.5。

## 修复与兼容性

- LiveStatus 增加可空的 scheduleId 及可选的 scheduleKnown。新版服务端明确无卡片绑定时返回 scheduleKnown=true；旧客户端仍可忽略新增字段，新版客户端也可识别旧服务端缺失字段并保留前后 2 小时的有界兼容匹配。
- 服务端和独立模式共用 Core 的直播场次状态：平台未提供开播时间时固定首次检测时间，断流后平台重置 live_time 时继续使用首次开播时间；同一直播间 30 分钟内（含边界）恢复仍属于原场。
- 日程与统计继续共用绑定：无预告开播补建“开播补录”卡片，新场只在前后 2 小时（含边界）内复用有效预告；取消、已占用和其他直播间的卡片不会被误用。
- 请求失败不作为下播；连续离线检查不延长合并窗口；已删除或取消的卡片不会被后续轮询恢复。
- 数据库增量增加 绑定归属状态列；旧数据默认保持“未知”，不批量重写历史日程，不根据时间接近补造历史绑定。迁移摘要覆盖新增直播状态和绑定关联。

## 升级与回滚

升级前备份完整 SQLite 数据和配置，使用一致性备份或停服后连同必要 WAL 一并备份；保留旧镜像、编译产物和更新代理配置。新字段为可选，旧客户端仍可读取现有字段；旧客户端无法理解明确无绑定的语义，建议升级配套桌面版本。

本版不自动删除历史日程或统计。发生网络失败时等待后续有效观测，不伪造中间数据。30 分钟内主动下播再开可能合并为续播；超过两小时或提前两小时以上的预告会保留原预告并另补本场卡片。
