# 推历 OshiCal 桌面端 0.3.23-beta.3 测试版

本版相对 `0.3.23-beta.2` 改善粉丝变化弹窗，新增主播个人主页入口和日程卡片胶囊显示开关。

## 新增、修复与体验变化

- 粉丝变化弹窗的标题和关闭按钮固定在顶部，滚动下方内容时可随时关闭；隐藏内容区与历史明细区右侧的滚动条，保留滚轮、触控板、触摸滚动及历史表头吸顶。YouTube 订阅者变化弹窗同步适用。
- 主播库“更多”菜单新增“进入个人主页”，B 站主播打开个人空间，YouTube 主播打开频道主页；使用系统默认浏览器，打开失败时显示错误提示。
- “设置 → 本设备设置 → 日程卡片”新增两个独立开关：“显示日程类型胶囊（预约、文本、图文等）”和“显示直播间归属胶囊”。默认开启，切换立即生效、自动保存，并应用于时间线和日历视图。
- 日历视图支持显示直播间归属胶囊，胶囊按卡片宽度换行，过长的归属名称省略显示。
- 关闭两类胶囊且没有其他状态时收起底部空白；“手动锁定”“来源有变化”提示保留。切换主题、自定义配色或恢复默认配色时保留胶囊显示选择。

## 数据、配置与兼容性

- 两项胶囊偏好保存于当前设备的界面设置，重启后保留，不同步到其他设备；旧配置缺少新字段时默认开启。
- 无新增数据库迁移、环境变量或 API，不改变日程数据、采集频率及同步协议；沿用 `0.3.23-beta.2` 的兼容性要求，服务端版本不变。
- 隐藏胶囊不会删除来源或直播间归属，也不影响双击进入直播间。

## 下载、安装与渠道

- 版本与标签：`0.3.23-beta.3` / `desktop-v0.3.23-beta.3`，属于 beta 测试版渠道；对外发布时 Release 必须标记为 prerelease，并维护固定 `desktop-beta` 清单，不移动正式版更新清单。
- 普通用户下载 Windows x64 **NSIS 安装包** `OshiCal_0.3.23-beta.3_x64-setup.exe`；已安装用户可在“设置 → 软件更新”中检查正式发布的更新。
- 正式发布流程的更新包使用 Tauri 签名校验；本次本地构建仅供手动安装，不生成自动更新签名文件。
- 当前未配置 Windows Authenticode 代码签名，Windows 可能提示“未知发布者”。
- 经用户明确要求，本次允许本机构建，缓存与交付安装包位于 D 盘；已有本地 beta.3 安装包保留，新包放入独立子目录。本次不发布 GitHub Release。

## 升级前操作、已知限制与回退

- 升级前退出客户端，备份完整数据目录和连接配置；无新增备份要求。
- 本地新包沿用 `0.3.23-beta.3` 版本号；已安装早先本地 beta.3 的用户请手动运行新安装包，同版本自动更新不会触发。
- 滚动条隐藏后无法拖动滑块，可用滚轮、触控板或触摸滚动；主页跳转依赖系统浏览器及平台网络连接。
- 已完成前端类型检查、生产构建、Windows x64 release 编译和 NSIS 打包，安装包复制前后 SHA-256 一致，三项界面改动均已包含于前端产物。桌面实际交互与自动更新仍待验证。
- 如需回退可重新安装此前保存的安装包；回退前保留备份。较旧版本不识别新增偏好，可能恢复旧版胶囊显示方式。
