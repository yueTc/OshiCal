# OshiCal Desktop 0.3.21-beta.5 发布说明

本版相对 `0.3.21-beta.4`，调整主播库、日程页与设置页的顶部信息层级，并让关键标题和操作在滚动时持续可见。

## 本版变化

### 操作按钮

- “新增日程”及设置页的主题色实底主按钮（包括保存设置、保存镜像、立即更新服务器、开启月相、下载并安装、扫码登录及确认弹窗）的文字和图标统一固定为白色，不再随配色切换为黑色；外观选中的勾选标记同步使用白色。浅色次要按钮、背景、布局和交互状态保持原样。

### 主播库

- 删除标题下方的说明文字“管理日程订阅、开播通知、直播数据和官号来源。”，让顶部信息更简洁。
- 修复月相、粉丝数及右侧操作区挤压订阅开关的问题：姓名与 UID 仍在第一行左侧，月相等信息仍在第一行右侧；三个订阅开关独立使用下方完整内容宽度，保持单行，官号仍在其下方。
- 不缩小开关、字号或间距；极窄内容区域可横向滚动开关行，不折行或压缩开关。长姓名省略显示，保留 UID 同行。
- 主播姓名与 UID 在第一行垂直居中，视觉上略微下移，与右侧月相和操作按钮对齐；头像、订阅开关和官号的位置不变。

### 直播日程

- “直播日程”标题、整排操作按钮和日期导航条改为同一吸顶区域，向下滚动日程内容时始终保持在窗口顶部，并在吸顶区域下方保留内容间隔。
- 吸顶区域只在真正贴住窗口顶部后显示背景遮罩，避免未滚动时遮挡页面顶部的提示信息。

### 设置页

- 左上角改为与主播库一致的标题样式，移除标题上方的 `PREFERENCES` 小字。
- 删除标题下方的说明文字“连接与多设备同步、服务端采集参数，以及只属于这台设备的通知和运行偏好。”。
- “设置”标题和“保存设置”按钮组成同一吸顶区域，向下滚动设置内容时始终保持在窗口顶部，并在吸顶区域下方保留内容间隔。
- 删除服务器模式下“二维码由服务器生成，Cookie 只加密保存在服务器。”的说明文字。
- 在“B 站登录与 Cookie”标题旁增加服务端登录状态胶囊，区分“服务端已登录”和“服务端未登录”。
- 精简设置页各卡片中重复或冗长的说明文字，涉及运行模式、多设备同步、服务器更新、采集参数、网络代理、直播统计、界面配色、提醒与运行、软件更新和日程模型。
- 设置页的直播数据统计开关改为文字位于开关前，并修正表单内开关被压成上下排列的问题。
- 自定义配色区域仅在选中“自定义配色”后显示。
- 移除日程识别模型中的密钥状态提示块，思考程度控件上移填补该位置。
- 服务端与客户端的更新渠道切换器统一移到更新卡片右上角，删除“更新渠道”文字并改为胶囊样式。
- 渠道切换提示与“设置已保存”提示改为显示 3 秒后自动消失。
- “自动分析动态文字和日程图片”的开关移到日程识别模型卡片右上角，并隐藏可见文字、保留无障碍名称。
- 删除“本设备设置”的说明文字；思考程度由分段按钮改为下拉选择，“自动”选项显示为“关闭”。
- 吸顶区域只在真正贴住窗口顶部后显示背景遮罩，避免未滚动时遮挡页面顶部的提示信息。
- 窄屏下继续采用单行标题与保存按钮布局，并缩小顶部区域占用。

## 数据、配置与兼容性

- 不改变数据库结构、API、环境变量或默认设置，无需迁移数据。
- 不改变更新渠道、版本比较或自动更新行为。
- 本次是桌面端本地构建测试包，不影响服务端版本。

## 下载与安装

- 版本：`0.3.21-beta.5`。
- 普通用户使用本地 Windows x64 NSIS 安装包：`OshiCal_0.3.21-beta.5_x64-setup.exe`。
- 已安装用户通常可在“设置 → 软件更新”中检查已发布的更新；本次仅交付本地安装包，不能通过在线更新取得本次未发布的修订。
- 这是一次本地验证构建，尚未发布 GitHub Release，也不会移动正式版或测试版更新清单。
- 本次本地构建未生成 Tauri updater 签名文件，也未启用 Windows Authenticode 代码签名，因此 Windows 可能显示未知发布者提示。

## 升级前操作与回滚

- 使用本地数据模式时，建议先备份 `%APPDATA%\com.oshical.desktop\oshical.db` 及相关 `-wal`、`-shm` 文件。
- 使用服务端模式时，桌面端本身不保存主日程数据，无需迁移服务端数据。
- 如需回滚，可重新安装上一份桌面安装包；本次本地构建不会修改远端更新清单。

## 已知限制

- 本次安装包在本机按用户明确要求构建；构建与文件校验结果另附于交付目录。真实窗口滚动、不同窗口宽度下卡片显示及覆盖安装仍需人工确认。
- 本地构建不包含 updater 签名，不能直接用于测试版或正式版自动更新发布。
