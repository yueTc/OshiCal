# 界面与交互规格

## 1. 信息架构

```text
┌──────────────────────────────────────────────────────────┐
│ 推历 OshiCal  [日程] [主播库] [设置]     连接状态  刷新         │
├───────────────┬──────────────────────────────────────────┤
│ 7 天日期轴     │ 日程主体：网格/时间线                    │
│ 搜索主播       │ 每条显示头像、主播、主题、时间、来源     │
│ 订阅列表       │ 点击卡片打开直播间                       │
│ 开关状态摘要   │ 空状态/加载/错误/离线                    │
└───────────────┴──────────────────────────────────────────┘
```

### 主要页面

0. **左侧栏**：桌面端固定定位，右侧提供拖拽手柄，可在 210–420px 间调整宽度并用 localStorage 持久化；双击恢复 244px，方向键可微调；≤960px 自动变为紧凑图标栏，移动端变为底部导航。
1. **日程**：默认页。从所选日期起连续显示 7 天，可切换日历网格或时间线视图。
2. **主播库**：B 站搜索、添加订阅、官号关联、别名管理、日程/通知开关、单主播重新拉取和阶段进度。
3. **设置**：本地/服务器模式、服务器地址、Token、动态与开播间隔、通知开关、托盘/开机自启、B 站 Cookie、日程模型配置、连接测试和固定示例图模型自检。

## 2. 视觉规范

- 风格：轻盈、信息密集但不拥挤的“直播节目单”，偏粉色品牌色但避免整屏粉。
- 背景：`#FFF8FB`
- 表面：`#FFFFFF`
- 主色：`#E94F88`
- 主色深：`#B83263`
- 文本：`#241820`
- 次文本：`#75636D`
- 边框：`#EEDDE5`
- 成功/直播中：`#16A46B`
- 警告：`#DB8A20`
- 错误：`#D83A52`
- 圆角：卡片 16px，按钮 10px，输入 10px。
- 间距：4/8/12/16/24/32。
- 字体：系统字体栈，标题 600，正文 400；日程时间使用等宽数字。
- 阴影：仅浮层与拖拽状态使用，日程卡片以边框区分。

## 3. 7 天日程视图

- 默认显示从今天开始的连续 7 天。
- 前移/后移每次移动 1 天，不是整页 7 天切换。
- 提供“回到今天”按钮。
- 视图模式可在“日历网格”和“时间线”之间切换并持久化。
- 时间线桌面双列、窄屏单列；网格按内容区宽度自动显示 7 / 5 / 3 / 1 天，不出现横向滚动条。
- 网格支持鼠标/触屏横向拖动、触控板横滑、Shift+滚轮和左右方向键切换日期；拖动时日期条实时预览目标日期，松手吸附到最近日期。
- 网格轨道预渲染约 5 周日期，拖动可一次跨多天；当前范围无日程时仍保留网格供继续拖动。
- 空日期仍保留日期标题，避免用户误以为数据缺失。

## 4. 日程卡片

- 必显：时间、主播头像、主播名、直播主题、来源标识。
- 直播中：绿色状态点 + “直播中”标签 + 呼吸动画。
- 已开始未开播：状态点变灰，不冒充直播中。
- 卡片整卡单击打开直播间，键盘 Enter 同样可用。
- 桌面端右键、移动端长按打开菜单；菜单提供编辑、删除、查看来源。
- 手动锁定或来源变化时显示文字标识，不使用颜色作为唯一信号。
- 已取消日程不出现在未来 7 天窗口；历史视图保留。
- 来源标识：文本、预约、图片、手动。
- 悬停只提升边框和背景，不做大幅位移。
- 加载态使用骨架屏；空态提供“添加订阅”；错误态显示重试。

## 5. 添加订阅流程

1. 在搜索框输入昵称或 UID。
2. 显示搜索结果卡片。
3. 点击“订阅”，默认开启日程订阅和开播通知。
4. 进入“主播库”后可添加官号、编辑别名和关闭开关。
5. 失败时保留搜索词并显示可读错误。
6. 每张主播卡片提供重新拉取图标；刷新时显示服务端或本地核心实际上报的阶段、百分比和进度条。

## 6. 设置流程

- 数据源切换需先测试连接。
- 本地模式隐藏服务器地址和 Token。
- 服务器模式显示连接状态、最近事件序号、重连按钮。
- 日程模型配置用于动态文字与图片；同一文字版本/图片缓存一次。
- “拉取模型”调用当前 Base URL 的 OpenAI-Compatible `/models`；支持搜索筛选并回填模型 ID，同时保留手动输入自定义 ID。
- “测试模型”使用内置 `10.26–11.01` 枝江娱乐直播日历，显示连通性、端到端延迟、返回事件数、基准匹配数和成功率。
- Cookie 输入框不回显原值，只显示“已配置/未配置”。
- B 站 Cookie 卡片提供“登录窗口自动获取”和“扫码登录”；扫码弹窗显示二维码与实时状态，登录成功后自动刷新已配置状态。
- 已保存 Cookie 时显示“退出登录”；点击后必须二次确认，只删除本机凭据，不修改服务端环境变量。
- 自动获取登录窗口只加载 B 站官方域名；完成登录并检测到 Cookie 后自动保存并关闭。
- 设置页提供系统托盘行为说明和开机自启开关，自启默认关闭。
- 服务器模式切换前展示导入冲突摘要，用户统一选择处理策略。
- 设置中不提供开播前提醒，只提供实际开播通知。
- 保存成功给出明确反馈，不用 Toast 作为唯一状态。

## 7. 状态与无障碍

- 所有表单包含 label、错误文本和键盘焦点。
- 颜色不是唯一状态信号，必须配合文字或图标。
- 触控目标最小 40px，移动端 44px。
- `prefers-reduced-motion` 下关闭呼吸、滑入和骨架动画。
- 页面标题层级正确；图表不使用；图片有 alt。
- 桌面最小窗口 1080×720；窄屏在 900px 以下切换为单列布局。

## 8. 前端安全

- 不使用 `dangerouslySetInnerHTML`。
- Token 仅保存在内存。
- 所有外链通过后端校验后使用 Tauri opener。
- 不把敏感设置写入 localStorage。
- API 错误文本按纯文本渲染。












## 9. 托盘与连接状态

- 关闭窗口后进入托盘，托盘菜单包含“打开、立即刷新、退出”。
- 托盘图标状态区分正常、离线、同步冲突。
- 服务器模式显示 WebSocket 连接状态、最近事件序号和待同步队列数量。
- 离线时允许本地手动编辑，并明确显示“待同步”标记。
- 导入冲突使用独立面板，禁止用自动消失提示代替确认。
