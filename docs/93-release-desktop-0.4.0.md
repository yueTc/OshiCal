# 推历 OshiCal 桌面端 0.4.0 正式版

本版相对上一桌面端正式版 `0.3.22`，汇总 `0.3.23` 测试周期的全部用户可见变化，并同步进入 `0.4.0` 正式版：新增 YouTube 主播支持、最近直播与直播数据查看、完善日程归属和直播间合并，并集中优化客户端设置、侧栏和更新体验。建议服务器模式搭配 OshiCal Server `0.4.0` 使用。

## 新增功能与体验变化

### YouTube 与多平台主播库
- 新增可选的 YouTube 主播库支持，可按频道搜索、添加订阅、关联官号、查看直播状态，并打开频道主页。
- YouTube 功能默认关闭；可在设置页填写 Data API Key，使用 OAuth 登录，或导入受限的网页会话以读取会员社区帖。
- 支持 YouTube 预约直播、开播与下播、最近直播、社区动态、Super Chat / Super Sticker、会员事件及聊天场次统计。
- B 站与 YouTube 同时启用时显示平台徽标；仅启用 B 站时隐藏多余平台标识，主播卡片变窄时优先保留主播名称和“直播中”状态。

### 最近直播与直播数据
- 主播库“更多操作”新增“查看最近直播”，可查看最近最多 50 场已采集直播，并直接打开对应场次的直播数据。
- 直播数据包含时长、估算营收、付费与互动人数、弹幕和完整度提示；消费明细与场次统计按现有采集口径展示。
- 点击“最高同时在线”可查看公开高能用户数曲线，支持整场、最近 1 小时、最近 3 小时及悬停/拖动时间范围。
- 直播期间按需增量读取曲线采样；下降和真实 0 保留，缺失区间断开显示，不插值或补零。

### 日程归属、去重与刷新
- 同一直播间、开始时间相差不超过 10 分钟的自动日程优先按直播间合并，不再要求参与者名称完全重合。
- 不同直播间的日程不会仅因参与者重合而合并；已绑定不同直播场次的卡片保持独立。
- B 站转发动态会区分原文、转发附言和原作者信息，不把转发者自动视为参与者或直播间主人。
- 修正单人日程的参与者归属，避免纯转发或应援他人的内容被错误收入转发者日程；被拒绝的不相关结果不再占用预约时段。
- 同一主播刷新继续旧到新串行；识别失败按 1、5、15、30 分钟退避，内容或识别配置变化后可重新尝试。

### 客户端界面与运行体验
- “设置 → 软件更新”精简版本与渠道重复信息，保留明确的正式版/测试版切换。
- 修复日程、主播库和设置页吸顶标题左右边缘色差。
- 运行模式卡片将标题移动到图标右侧；B 站账号风控提示改为标题栏右侧圆形感叹号，悬浮或键盘聚焦时显示。
- 设置页网络代理的端口、测试目标和“测试代理”按钮保持同一行；移除冗余代理地址和日程即时生效说明。
- 设置范围标签统一显示为“桌面端”。
- 左侧主播快捷列表移除“我的主播”标题；人数徽标移动到“主播库”右侧，并缩小导航与快捷列表间距。
- 侧栏缩窄时品牌副标题保持单行并以省略号截断。
- 主播快捷条目双击或按 Enter：直播中进入直播间，未直播打开个人主页或 YouTube 频道；右键菜单保留显式“进入直播间”。
- 新增单实例保护：开机自启、快捷方式或再次启动应用时唤醒已有窗口，不重复创建进程和托盘图标。
- 首次连接已有服务端时优先采用服务端模型配置，避免错误覆盖 API Key 绑定；连接测试同时验证鉴权接口。
- Windows 安装器固定使用简体中文并隐藏语言选择器。

## 数据、配置与兼容性

- 桌面端启动时会自动增量升级本地数据库，新增 YouTube、直播采样、场次状态和相关索引；升级前应备份完整数据目录及必要的 WAL。
- YouTube API Key、OAuth 刷新凭据和网页会话使用加密或系统凭据存储；主密钥与数据库必须一起备份。
- 服务器模式建议两端均为 `0.4.0`。服务端同步协议升级为 schema 3，旧客户端不能安全解析新同步数据；升级桌面端时应同步升级服务端。
- 新服务端可继续保留 `stable` 与 `beta` 渠道；测试版会同时读取正式版和测试版清单并按 SemVer 选择较高版本，定时更新不会自动降级。
- 无新增桌面端必填环境变量。模型、代理、托盘、开机自启、通知与连接配置继续沿用本地设置。
- 旧场次、停服或断线期间不会补造直播采样；人数曲线表示公开高能用户数，不等同于全体观众真实同接。

## 下载、安装与更新

- 正式版本：`0.4.0`；正式标签：`desktop-v0.4.0`。
- 普通用户下载 Windows x64 **NSIS 安装包** `OshiCal_0.4.0_x64-setup.exe`。
- 已安装用户可在“设置 → 软件更新”选择“正式版”并检查更新；自动更新包使用 Tauri 更新签名校验。
- 当前发布流程未配置 Windows Authenticode 代码签名，Windows 可能显示“未知发布者”；请仅从本项目正式 Release 或客户端内更新。
- 测试版渠道继续维护固定 `desktop-beta` 清单；本正式版发布不会使用测试版清单替代正式更新源。

## 升级前操作、已知限制与回退

- 升级前退出客户端，备份完整客户端数据目录、服务器连接配置、数据库 WAL 和凭据主密钥；服务器模式还应先备份服务端数据库与密钥文件。
- YouTube 社区页目前只解析首屏，预约直播只检查最近 20 个上传；频繁搜索可能消耗用户自己的 API 配额。
- 已采集历史不会自动补造，旧错周记录不保证自动修正；需要时应在备份后按来源核对并手动处理。
- 单实例范围是当前 Windows 用户会话；不同 Windows 用户会话仍可各自运行一个实例。
- 如需回退，优先保留 `0.4.0` 数据和备份后手动安装 `0.3.22`；不要只回退程序而继续使用未经确认兼容的新数据库。自动更新不会替用户执行降级。
