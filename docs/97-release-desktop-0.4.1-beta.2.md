# 推历 OshiCal 桌面端 0.4.1-beta.2 测试版

## 相比 0.4.1-beta.1

- 修复 B 站联动日程跳到转发主播直播间的问题。已订阅 A、未订阅 B 时，只要公告确认 A 参演，仍会收录联动日程；确认 B 是房主且能查到房间时，卡片会打开 B 的直播间。不会自动订阅 B。
- 无法确认联动房间时，日程照常显示，保留已识别的房主信息，但卡片和右键菜单都不会猜测参演者的房间，也不会把主播 UID 当作房间号。

## 下载、升级与回退

- GitHub 测试版标签为 `desktop-v0.4.1-beta.2`，使用 `desktop-beta` 更新清单。新装用户下载 Windows x64 **NSIS 安装包** `OshiCal_0.4.1-beta.2_x64-setup.exe`；已安装用户可在“设置 → 软件更新”选择“测试版”并检查更新。更新包由 Tauri 签名校验；当前发布流程没有配置 Windows Authenticode 代码签名，Windows 可能显示“未知发布者”。
- 相对上一测试版没有新增数据迁移、环境变量或 API 配置。升级前请退出客户端并备份数据目录与凭据；服务器模式建议同步升级服务端，因为日程房主由执行识别的一端决定。
- 已经写入错误链接的旧卡不会因安装更新自动清理。需要更正时，先核对原动态与实际直播间，再手动编辑卡片。如需回退，先备份当前数据，再手动安装上一版本；自动更新不会降级。
