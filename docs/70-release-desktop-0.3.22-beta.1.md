# 桌面客户端 0.3.22-beta.1（测试版）

本版基于上一桌面正式版 0.3.21，更新独立采集核心，并新增直播人数变化曲线。服务器模式建议配合已发布的服务端 0.3.30-beta.5 或更新版本。

## 新增与体验

- 在日程的“查看直播数据”中，点击“最高同时在线”卡片即可查看本场人数变化曲线；支持整场、最近 1 小时、最近 3 小时，悬停或拖动时间滑块查看具体采样值，滑块支持方向键。
- 本地模式读取电脑上的采样，服务器模式读取所连接服务器的鉴权分页接口；不混用两个来源。直播期间打开曲线每 30 秒自动读取新增点，也可手动刷新；返回统计或关闭窗口会停止该视图的定时读取。
- 曲线统计口径明确为 B 站公开高能用户数，不是全体观众真实同接。人数下降和真实 0 保留，缺失和较长的未采集区间断开显示，不插值、不补零。老场次只有峰值、没有采样时明确显示暂无历史。
- 服务器离线、旧版接口缺失或读取失败会显示原因并允许重试；曲线读取失败不会把已有曲线清空成零。

## 独立模式对齐服务端

- 共用 crates/core 已包含约每 30 秒人数采样及原始观测时间、全场峰值、断线和下播处理。人数采样独立存表，不将整条曲线反复写进同步历史，也不保存原始弹幕正文。
- 自动识别得到相同日程、来源或不变直播汇总时减少重复同步记录；新增本地同步历史维护：进入独立模式约 60 秒后首轮，之后每 1 小时检查，保留 7 天／最新 10,000 条／20 MiB JSON 内容，先到的限制生效。只清同步历史，不删场次、日程或待提交修改；不自动 VACUUM。
- 带入上一桌面版之后的核心改进：按独立主播并行处理动态，同一主播内部按顺序处理；相同进行中刷新可共享结果，避免重复识别；失败识别按 1、5、15、30 分钟退避（最长 30 分钟），到期在后续正常刷新中重试。
- 每条动态最多取原始前两张图片用于识别，不因前两张失败而继续尝试第三张；原图片链接仍保留。保留开始时间已过去的有效日程，并按动态发布时间确定周表所属周，避免旧周表错套到当前周。

## 数据与兼容性

- 升级时本地数据库自动新增人数采样表及索引；旧场次不回填无法恢复的历史。采样随场次保存，删除对应主播订阅会级联删除。关闭统计或客户端未运行期间不会补造采样。
- 服务器模式曲线需要服务端 0.3.30-beta.5 新增的接口。旧服务端仍可使用原有日程和汇总功能，只是曲线不可用；服务器曲线按需读取，暂不做离线缓存，断网时无法首次读取。
- 本次仅发布桌面测试版，不改服务器容器、服务端版本或服务端更新清单。共用前端的新曲线也可供未来重新发布的服务端 Web 页面使用，现网 Web 页面不会因本次桌面发布自动变化。
- 无新增运行时依赖和必填环境变量；浏览器交互回归所需 Playwright 仅安装在 CI 临时目录。升级前建议备份客户端完整数据目录；若需回滚，先保存当前数据，再安装上一版。恢复旧数据库备份会丢失备份之后的新记录，不能直接覆盖正在运行的数据库。

## 下载与升级

- 本版为 desktop-v0.3.22-beta.1，发布标记为 prerelease，维护 desktop-beta 清单，不替换正式版 latest。
- 普通用户下载 Windows x64 NSIS 安装包（.exe）；已安装用户可在“设置 → 软件更新”切换到测试版渠道并检查更新。需要保留便携使用方式的用户可选择发布页上的对应编译产物（以实际附件为准）。
- 自动更新包使用 Tauri 签名校验；当前发布流程未配置 Windows Authenticode 代码签名，系统可能提示未知发布者。
- 构建、测试、签名和发布均通过 GitHub Actions 完成；不在当前工作区或当前主机本地编译。
