# 推历 OshiCal 桌面端 0.3.23-beta.8 测试版

本版相对 `0.3.23-beta.7` 调整主播库的平台标识和窄宽度布局：未开启 YouTube 主播库时不再显示多余的 Bilibili 徽标；主播卡片变窄时，优先压缩平台徽标和 UID，尽量保留主播名称。

## 修复与体验变化

- 未开启 YouTube 主播库时，主播卡片、搜索结果和新关联账号列表不再显示 `Bilibili` 平台徽标。
- 开启 YouTube 主播库后，Bilibili 与 YouTube 平台徽标继续保留，便于区分平台。
- 主播卡片标题行缩窄时，平台徽标和 UID 会优先收缩；主播名称最后才进入省略号截断。
- “直播中”状态保持固定显示，不随平台徽标和 UID 优先折叠。
- 单实例保护、开机自启、通知、日程和直播数据逻辑不变。

## 数据、配置与兼容性

- 无数据库迁移、同步 schema、API 字段、环境变量或默认设置变更。
- YouTube 开关的保存方式和平台过滤逻辑不变，只调整界面显示。
- 本版只影响桌面端；服务端无需同步升级，仍按现有 `stable` / `beta` 渠道更新。

## 下载、安装与渠道

- 版本与标签：`0.3.23-beta.8` / `desktop-v0.3.23-beta.8`。
- 普通用户下载 Windows x64 **NSIS 安装包** `OshiCal_0.3.23-beta.8_x64-setup.exe`。
- 已安装用户可在“设置 → 软件更新”中选择测试版并检查更新；本版会更新固定 `desktop-beta` 清单，不移动正式版更新清单，也不会自动降级。
- 更新包使用 Tauri 签名校验。当前发布工作流没有配置 Windows Authenticode 代码签名，Windows 可能显示“未知发布者”，这与 Tauri 更新签名不是同一套机制。

## 升级前操作、已知限制与回退

- 升级前退出客户端并备份完整数据目录、服务器连接配置和凭据。
- 本版未在本机执行构建或测试；构建、测试、签名和产物验证由 GitHub Actions Release 工作流执行，结果以该工作流为准。
- 需要真实验收“关闭 YouTube 主播库”“仅有一个平台时隐藏 Bilibili 徽标”“窗口变窄时名称最后截断”三个场景。
- 需要回退时安装此前保留的 `0.3.23-beta.7` 桌面测试版并恢复必要的本地数据备份。
- 本版只准备 beta；正式版须待测试反馈确认后另行批准。发布时将本文原文写入对应 GitHub Release 正文。
