# 推历 OshiCal 桌面端 0.3.23-beta.9 测试版

本版相对 `0.3.23-beta.8` 集中修正客户端界面与快捷交互：精简软件更新卡片、修复吸顶标题边缘色差、优化运行模式和 B 站账号提示，并调整左侧主播快捷列表。

## 修复与体验变化

- “设置 → 软件更新”不再在版本号上方重复显示“当前版本 · 测试版/正式版渠道”，渠道继续由“正式版 / 测试版”切换按钮明确展示。
- 修复直播日程、主播库和设置页吸顶标题在左右边缘露出不同页面底色的问题；吸顶背景现在覆盖整个主内容区域，移动端覆盖整屏宽度。
- “运行模式”中的“本地模式 / 服务器模式”标题移动到各自图标右侧，减少卡片纵向占用。
- B 站 Cookie 卡片不再使用占满整行的账号风控警示条，改为标题栏右侧的圆形感叹号；鼠标悬浮或键盘聚焦时显示原提示。
- 左侧主播快捷列表移除“我的主播”分组标题。
- 设置页移除日程卡片“立即生效并自动保存”说明，并将本地设置范围标签统一改为“桌面端”。
- 设置页网络代理卡片移除冗余地址提示，“测试代理”按钮与端口、测试目标保持同一行。
- 缩小左侧“设置”导航与主播快捷列表之间的上下留白。
- 左侧导航中的主播人数徽标从“日程”移动到“主播库”右侧。
- 左侧品牌副标题在侧边栏缩窄时保持单行，空间不足时显示省略号。
- 左侧主播快捷条目双击或按 Enter 时，直播中的主播进入直播间；未直播时改为打开个人主页，YouTube 频道则打开频道主页。右键菜单仍保留显式“进入直播间”入口。
- 单实例保护、开机自启、通知、日程、直播数据和更新渠道选择逻辑不变。

## 数据、配置与兼容性

- 无数据库迁移、同步 schema、API 字段、环境变量或默认设置变更。
- 本版只影响桌面端；服务端无需同步升级，正式版与测试版更新渠道仍可正常切换。
- 本构建仅用于本地验收，不发布、不移动 `desktop-beta` 或正式版更新清单。

## 下载、安装与渠道

- 版本：`0.3.23-beta.9`；对应正式发布标签应为 `desktop-v0.3.23-beta.9`。
- 本地测试产物为 Windows x64 **NSIS 安装包** `OshiCal_0.3.23-beta.9_x64-setup.exe`。
- 本次为本地未签名构建，不包含 Tauri updater `.sig` 或 `latest.json`；不能用于在线自动更新，也不会更新测试版清单。
- Windows Authenticode 代码签名未启用，安装时 Windows 可能显示“未知发布者”。

## 升级前操作、已知限制与回退

- 升级前退出客户端，并备份完整数据目录、服务器连接配置和凭据。
- 本版需要实际验收软件更新卡片、吸顶边缘、运行模式布局、B 站账号提示、设置页代理同行布局与“桌面端”范围标签、侧栏缩窄时的品牌副标题省略效果，以及左侧主播快捷列表的直播/未直播双击行为。
- 需要回退时安装此前保留的 `0.3.23-beta.8` 桌面测试版，并恢复必要的本地数据备份。
- 本版只准备本地 beta 测试包；正式版须待测试反馈确认后另行批准。
