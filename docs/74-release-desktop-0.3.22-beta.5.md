# 桌面客户端 0.3.22-beta.5（测试版）

本版相对已发布的桌面测试版 0.3.22-beta.4，修复直播卡片绑定对旧服务端的兼容判断，并固定跨断流重连的首次开播时间。建议服务器模式同时升级至服务端 0.3.30-beta.7。

## 修复与体验

- 直播状态的显式卡片绑定增加 绑定归属标记。连接新服务端时，服务端明确表示“本场没有卡片”后，客户端不会回退高亮另一张预告；连接缺少该字段的旧服务端时，仍只使用实际开播前后 2 小时的有界兼容匹配。
- 跨断流重连后，直播状态的“开播时间”继续保留本场首次开播时间，不因平台重置 live_time 而跳动；实际日程卡片仍保持绑定，不另建卡片。
- 无预告开播、30 分钟内（含边界）续播、2 小时预告匹配、下播保留、删除/取消后不复建等规则与 beta.4 一致。
- 自动补卡仍只遵循主播的日程采集开关；重复轮询、请求失败和重启不会重复补卡或重复累计推流段。

## 兼容与限制

- 新增字段为可选字段，旧桌面数据库自动增量增加 绑定归属状态列；不批量重写历史日程，不凭时间接近补造历史绑定。
- 连接旧服务端且没有任何 绑定归属信息时，直播高亮最多使用实际开播前后 2 小时的兼容匹配；旧服务端本身仍不能补建无预告卡片。
- 30 分钟内主动下播再开可能按续播合并；提前或迟到超过 2 小时会保留原预告并另补本场卡片。阈值固定，不新增设置项。

## 升级与回滚

升级前备份客户端完整数据目录；服务器模式应同时备份服务端数据库和配置。在线 SQLite 使用一致性备份，或停服后连同必要 WAL 一并备份，不要覆盖正在运行的数据库。回滚前保留当前完整数据，再安装旧版；恢复升级前备份会丢失备份之后的新记录。

## 下载与更新渠道

- 发布标签为 desktop-v0.3.22-beta.5，标记为 prerelease，仅更新 desktop-beta 清单，不替换桌面正式版 latest。
- 普通用户下载 Windows x64 NSIS 安装包（.exe）；已安装用户可在“设置 → 软件更新”选择测试版渠道检查更新。其他产物以发布页实际附件为准。
- 自动更新包使用 Tauri 签名校验；当前发布流程未配置 Windows Authenticode 代码签名，Windows 可能提示未知发布者。
- 构建、测试、签名和发布通过 GitHub Actions 执行；正式版须另行确认。
