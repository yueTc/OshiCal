# 推历 OshiCal 桌面端 0.3.23-beta.10 测试版

本版相对 `0.3.23-beta.9` 继续调整设置页的紧凑度与提示方式：运行模式标题移动到图标右侧，B 站账号风控提示改为标题栏最右侧的悬浮提示。

## 修复与体验变化

- “运行模式”中的“本地模式 / 服务器模式”标题移动到各自图标右侧，说明文字继续独占下一行，减少卡片纵向占用。
- “B 站登录与 Cookie”不再使用占满整行的账号风控警示条。
- 卡片标题栏最右侧改为圆形感叹号提示；鼠标悬浮或键盘聚焦时显示原账号风控提示，减少日常界面的视觉噪音。
- 单实例保护、开机自启、通知、日程、直播数据和更新渠道选择逻辑不变。

## 数据、配置与兼容性

- 无数据库迁移、同步 schema、API 字段、环境变量或默认设置变更。
- 本版只影响桌面端；服务端无需同步升级。
- 本构建仅用于本地验收，不发布、不移动 `desktop-beta` 或正式版更新清单。

## 下载、安装与渠道

- 版本：`0.3.23-beta.10`；对应正式发布标签应为 `desktop-v0.3.23-beta.10`。
- 本地测试产物为 Windows x64 **NSIS 安装包** `OshiCal_0.3.23-beta.10_x64-setup.exe`。
- 本次为本地未签名构建，不包含 Tauri updater `.sig` 或 `latest.json`；不能用于在线自动更新。
- Windows Authenticode 代码签名未启用，安装时 Windows 可能显示“未知发布者”。

## 升级前操作、已知限制与回退

- 升级前退出客户端，并备份完整数据目录、服务器连接配置和凭据。
- 本版需要实际验收运行模式卡片布局，以及账号提示图标的鼠标悬浮和键盘聚焦效果。
- 需要回退时安装此前保留的 `0.3.23-beta.9` 或 `0.3.23-beta.8` 桌面测试版，并恢复必要的本地数据备份。
- 本版只准备本地 beta 测试包；正式版须待测试反馈确认后另行批准。
