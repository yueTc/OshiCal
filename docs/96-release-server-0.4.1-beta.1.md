# OshiCal Server 0.4.1-beta.1

修复团体直播改期后旧场次未取消的问题。公告使用栏目名、旧日程使用节目名时，在原有标题匹配无结果后，额外按来源账号、明确的原开播时间（前后 10 分钟）和完整参与者名单查找唯一旧场次。

- 仅对至少两名明确参与者的团播启用兜底；候选不唯一时不自动删除。
- 保留手动锁定、较新公告和同一公告中新场次的保护逻辑。
- 通过既有删除流程记录来源抑制与同步删除，防止旧日程被历史动态重新导入。
- 新增团播标题不同仍正确取消、保留提前一小时的新电台，以及错误来源、参与者不符、缺少原时间和多候选保护的回归用例。

这是 0.4.1-beta.1 测试版，发布到 beta 更新通道。

提供 GHCR 镜像、Linux x86_64 运行包和 Windows x86_64 运行包。构建与验证由 GitHub Actions 执行。
