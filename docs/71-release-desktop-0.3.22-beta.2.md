# 桌面客户端 0.3.22-beta.2（测试版）

本版基于 `0.3.22-beta.1`，整理弹窗关闭入口，移除与右上角 X 重复的底部“关闭”按钮，并优化“同接变化”弹窗的滚动体验与顶部操作可见性。桌面端版本递增为 `0.3.22-beta.2`；服务端版本与更新渠道不变。

## 本版变化

- 直播数据弹窗移除底部“关闭”按钮，统一使用右上角 X 或点击遮罩关闭。
- B 站扫码登录弹窗移除底部“关闭”按钮，保留“重新生成”操作，统一使用右上角 X 或点击遮罩关闭。
- 选择模型弹窗移除底部“关闭”按钮，统一使用右上角 X 或点击遮罩关闭。
- “同接变化”弹窗隐藏内容区可见滚动条，仍可用鼠标滚轮、触控板或拖动内容继续浏览。
- “同接变化”标题和右上角关闭按钮固定在弹窗顶部，滚动人数统计和曲线内容时保持可见。
- 移除“同接变化”中的统计口径说明、原始观测时间和空白区间插值说明，保留曲线、采样时间滑块及核心统计信息。
- 编辑日程、保存设置、删除确认、数据迁移等包含独立决策或主操作的弹窗不受影响，其“取消”“保存”“稍后”等按钮继续保留。

## 数据、配置与兼容性

- 不改变数据库结构、API、环境变量、更新渠道或默认设置，无需迁移数据。
- 本次只影响桌面客户端界面，不修改服务器版本，也不改变正式版更新清单或测试版更新清单。
- 升级前如使用本地数据模式，建议备份 `%APPDATA%\com.oshical.desktop\oshical.db` 及相关 `-wal`、`-shm` 文件。

## 下载与安装

- 版本：`0.3.22-beta.2`。
- 普通用户使用 Windows x64 NSIS 安装包：`OshiCal_0.3.22-beta.2_x64-setup.exe`。
- 本次为按用户要求生成的本地安装包，不发布 GitHub Release，也不移动 `desktop-beta` 或正式版更新清单；已安装用户不能通过在线检查取得本次本地构建。
- 本地构建未生成 Tauri updater 签名，且未配置 Windows Authenticode 代码签名，Windows 可能提示“未知发布者”。

## 升级与回滚

- 可直接覆盖安装本版；如需回滚，请重新安装上一份桌面安装包。覆盖安装前应先确认本地数据备份，避免以旧数据库备份覆盖安装后产生的新记录。
- 本包未执行真实安装、覆盖安装和自动更新验证；安装后请确认三个受影响弹窗均只能通过右上角 X 或遮罩关闭，并确认原有独立操作按钮仍可用。
