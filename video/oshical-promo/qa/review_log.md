## 2. 渲染期发现并修掉的问题

1. **每个页面的第一张截图可能取到空画布**（因为首帧还没被合成器提交）。→ 页面在 READY 前做三次 rAF + 250ms 等待，并让 `window.render` 在页面加载后的第一次调用返回一个"等两帧 + 150ms"的 Promise。修完 `--determinism` 通过。
2. **多 worker 拼接在段边界产出一帧空白**（`--workers 3`，第 300 / 600 帧；流复制 concat 在开放 GOP 上的典型症状）。→ 交付版用 `--workers 1` 渲染，段边界问题消失（代价 65s 渲染时间）。
3. **两处 drop 前"没有呼吸"**（26s 处只低 0.6 dB）。→ 24–26s 抽掉鼓与 bass、pad 提前收（`BAR * 0.55`），26s 前 ½ 拍 −11.5 dB。
4. **"停住"的段落被判成 dead air**（16.2–17.0s / 23.1–24.0s / 24.4–26.0s）。→ 全片加 1.000→1.030 的极慢推近，观感上一直在呼吸；现在只剩落版那 1.1s 的刻意定格。
5. **17.2–17.8s toast 展开成直播间时，toast 压在长大中的面板上**。→ toast 消失速度 ×3.2，面板改成深色 + alpha 渐入。

## 4. 已知保留项（不修，属于设计选择）

- **20.50s 是硬切**（提醒段 → 数据段）：落在拍点上，前面有一记 whoosh。
- **alert 段 17.27–17.43s 被标为"jumps"**：那是 0.8s 的形变展开（toast → 直播间），整幅面积在快速变化，属于有意的快速转场，不是闪烁。
- 中文用的是系统字体（Microsoft YaHei UI）。换机器渲染会有字形差异；正式投放用这一版导出的 MP4，不受影响。

## 5. 交付

- 成片：`out/final.mp4`（1920×1080 · 30fps · 30.00s · AAC 立体声）
- 封面帧：`out/poster.png`
- 抽帧对照：`qa/final-sheet.png`、`qa/final-phone.png`
- 重建：`sh build.sh`（默认 `--workers 3`；交付版请用 `--workers 1`，或直接用下面这条）
  ```bash
  node <skill>/scripts/render.mjs . --fps 30 --size 1920x1080 --workers 1 \
    --out out/final.mp4 --audio audio/music.wav
  ```
- 预览工作区：`node <skill>/scripts/editor.mjs . --size 1920x1080 --fps 30`
