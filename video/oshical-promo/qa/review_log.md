## 2. 这一版按反馈改了什么

1. **截图全部重抓**：从用户正在运行的 app 窗口抓 1700×1060（PrintWindow + DPI-aware），四张：时间线、日历网格、主播库、设置（裁出多设备同步）。仓库里 `docs/screenshots/` 的旧图（带金色标题栏）不再使用。
2. **补上主播库**：新增「主播库：一个人一个档案」整段，四个标签依次点亮，圈的是真实控件（订阅日程 / 开播通知 / 订阅直播数据 / 粉丝与趋势）。
3. **时间线与日历网格分开**：新增「时间线，还是日历网格？」整段，同一批日程用粉色擦除翻面，底部标签同步切换。
4. **图标换成真图标**：`public/oshical.svg` → `src-tauri/icons/icon.png`（片头、toast、解析节点统一）。
5. **去掉标题栏金色**：新截图是 borderless 窗口，只有右上角的最小化 / 最大化 / 关闭。
6. 时长 30 s → 36 s，配乐同步重写；落版服务端版本改为抓图里的 0.3.15。

## 3. 本轮修掉的问题

1. **擦除方向反了**：`wipeWindows` 的裁剪矩形从 `wipeX..W` 改成 `0..wipeX`，否则翻面后仍显示时间线。
2. **主播库的圈位置错**：原来圈的是三个紧挨的小开关（35px），改成圈每个主播的整排开关（365×45），并把对勾缩小到 13px。
3. **引导线穿屏**：从右侧标签连到左侧控件的虚线横穿整个卡片，删掉，改为"标签依次点亮 + 圈依次画出"。
4. **toast 压住文案**：toast 静止位置上移 114px（`restY = H - twH - 210`），光标落点也挪到 toast 右下。
5. **两种视图段窗口压住副标**：窗口改到 (380, 214)、宽 1150，慢推 7% 后仍不碰副标，底部标签也不被压。
6. **视图切换的小圆点乱飞**：删掉那个粉色指示点（原意是指切换按钮，实际落在「回到今天」上）。
7. **资源偶发加载失败导致白屏帧**：`loadImage` 加 6 次重试，并把 `window.render` 的挂载移到资源加载之后——加载失败时渲染工具会等，而不是拿到半成品页面把它渲成空帧。
8. **多 worker 拼接在段边界丢帧**：交付版固定 `--workers 1`（代价 80 s 渲染时间）。

## 5. 已知保留项

- **27.50 s 是硬切**（提醒段 → 数据段），落在拍点，前面有一记 whoosh。
- **25.2–25.4 s 被标为 jumps**：toast 形变成直播间的快速展开，属有意转场。
- **views / library 两段 still 比例偏高（83%）**：这两段主体是真实界面截图，刻意用 7% / 5.5% 的慢推代替元素运动；静帧对比看得到推进，逐帧检测低于阈值。
- 中文用系统字体（Microsoft YaHei UI）。换机器重渲会有字形差异，成品 MP4 不受影响。

## 6. 重建

```bash
node <skill>/scripts/audio.mjs build score.mjs          # 只要改音乐时
node <skill>/scripts/render.mjs . --fps 30 --size 1920x1080 --workers 1 \
  --out out/final.mp4 --audio audio/music.wav
node <skill>/scripts/editor.mjs . --size 1920x1080 --fps 30   # 预览工作区
```
